# Image Alt Text Suggestions

Alt text describes images for screen readers and search engines. Keep it descriptive and natural, include a keyword only when it genuinely fits, and avoid stuffing. Aim for under ~125 characters.

## Best practices

- Describe what is actually in the image.
- Do not start with "image of" or "picture of" (screen readers already announce it is an image).
- Include location or service context where natural (e.g. "Langley", "Invisalign").
- Leave decorative images with empty alt text (alt="").
