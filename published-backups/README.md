# Published Backups

This folder stores copies of blog posts and content exactly as they were published on astradentalcentre.com.

## Why keep backups here?

The `blog-drafts` folder holds working drafts. This folder is for the FINAL published version of each post, so there is a record of what actually went live and a safe copy to restore from if needed.

## Naming convention

Use the post slug and the publish date, for example:

- `invisalign-vs-braces-langley_2025-01-15.md`
- `emergency-dentist-langley_2025-02-01.md`

## What to capture

- The final post body (markdown or HTML).
- The published title tag and meta description.
- The URL it was published at.
- The publish date and any later refresh dates.

## Notes

- Save a fresh backup after any significant content refresh.
- Do not store credentials, API keys, or analytics IDs here.
